# LCC 曲线车道测试设计

## 1. 测试基本信息

- 测试项目：车道居中控制（LCC）
- 测试用例编号：TC-LCC-CURVE-001
- 需求编号：LCC-REQ-CURVE-001
- 测试类型：功能测试、基础性能测试
- 被测对象：当前冻结版本的 LCCController
- 仿真环境：HighwayEnv lane-keeping-v0
- 执行轮次：LCC-EXEC-003
- 测试性质：正式设计用例；首次正式执行前冻结标准

## 2. 测试目的

验证控制器在正弦曲线车道上的横向跟踪能力，检查横向误差、
稳定性、车道保持状态、车辆异常状态、观测数据及控制输出合法性。

## 3. 测试场景与前置条件

- 车道类型：正弦曲线车道（SineLane）
- 初始纵向位置：5.0 m
- 初始横向偏移：0.0 m
- 初始航向：与车道起始位置的切线方向一致
- 车辆初始速度：沿用环境默认值 8.3 m/s
- 执行步数：60
- 随机种子：42
- state_noise：0.0
- derivative_noise：0.0
- 控制器参数：保持当前冻结版本，不在本测试中调参
- 测试期间不得手动改变场景、控制器参数或判定阈值

## 4. 测量方法

每个控制周期记录：

1. 控制器输入：state、derivative、reference_state
2. 控制输出：steering_action
3. 仿真评价数据：车道局部坐标中的横向误差、航向误差、车速
4. 车辆是否在车道内、是否发生碰撞
5. 仿真 reward、terminated、truncated 状态
6. 场景参数、执行编号及源代码 SHA-256

横向误差以车道几何局部坐标计算，作为独立评价量；
不得仅使用控制器输入中的估计值替代仿真评价结果。

## 5. 项目级通过标准

REQ-CURVE-01：60 个控制周期内的最大绝对横向误差不超过 1.00 m。

REQ-CURVE-02：最后连续 10 个样本的绝对横向误差均不超过 0.25 m。

REQ-CURVE-03：所有评价样本均处于车道内，且未发生车辆碰撞。

REQ-CURVE-04：观测数据和评价数据均为有限数值；所有控制输出均为有限值，
并且满足环境动作空间约束。

以上为本学习项目的预设门槛，不是行业通用标准。
正式执行后不得为了使测试通过而修改门槛。

## 6. 测试判定

- PASS：所有通过标准全部满足。
- FAIL：至少一项通过标准不满足。
- ERROR：测试环境或执行脚本异常，导致无法完成有效判定。

FAIL 与 ERROR 必须区分：功能表现未达标属于 FAIL；
环境、接口或脚本异常导致无法得出有效结果属于 ERROR。

## 7. 证据与输出

归档目录：outputs/LCC-EXEC-003/

- raw_logs/：逐周期 CSV 原始数据
- run_summaries/：测试结果、指标、失败原因及执行元数据
- reports/：pytest 控制台日志、JUnit XML、HTML 报告

## 8. 与探索性测试的关系

先前曲线运行仅用于风险识别，不作为本正式用例的执行记录。
正式结论以 LCC-EXEC-003 的实际执行证据为准。
